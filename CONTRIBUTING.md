# Contributing to Frakment

Thanks for contributing to Frakment.

Anyone may report an issue, join a discussion, or propose a change through a pull request from a fork.

Check the repository's own contribution guide for its development and validation steps.

All changes to a protected default branch must be submitted through a pull request, including changes from Developers and Maintainers.

The owner reviews pull requests and is the only person who merges changes to protected default branches.

The owner-only bypass is reserved for exceptional situations, and pull requests are the normal path.

See the [Frakment contributor governance guide](https://github.com/frakment/.github/blob/main/GOVERNANCE.md) for contributor levels, promotion, Teams, and repository access.
